# Gold Trade Chart

ブラウザだけで動く、チャート表示サイトです。
ローソク足・出来高に加えて、出来高系インジケーターを2種類表示できます。

## 公開ページ

GitHub Pages で公開する設定になっています(Settings → Pages → Source を「GitHub Actions」にすると有効になります)。

- チャート: https://shomayamamoto-ai.github.io/Gold-trade/
- 教科書: https://shomayamamoto-ai.github.io/Gold-trade/guide.html

## 教科書(guide.html)

全12章。チャートの基本、銘柄の特徴、価格を動かすもの、インジケーター、手法、資金管理、心理、練習のしかた、自分で作って試す、よくある失敗、用語集、出典。

- 「事実(出典つき)」「実測(Binance のデータから計算)」「常識」「考え方」の4つの印で、根拠の種類を分けています
- 最初に読む道すじ(3コース)と、章ごとの読む時間の目安
- 各章の確認問題(48問。その場で答えと解説が出て、結果は端末に保存)
- 「チャートで試す」課題(17個。押すと、その課題に合った銘柄・時間足・インジケーターでチャートが開く)
- ページ内の検索( / キー)と、用語を押すとその場で意味が出るしくみ
- SNS でよく見る図や、よく教えられる決まりを、実データで確かめた節

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド不要)。教科書は `guide.html` です。

- 銘柄:最初から77銘柄を、8つの分類で選べます。一覧の「すべての銘柄から探す」から、Binance で取引されている1,300以上の通貨ペアも追加できます
  - 並び順は、利用者の TradingView の銘柄リスト(人気の銘柄が上)に合わせています。リストは米ドル建てですが、このサイトは Binance のデータを使うため、同じ銘柄の USDT 建てを載せています
  - 人気の銘柄(16):BTC、ETH、SOL、XRP、HYPE、LINK、INJ、XLM、ADA、BCH、DOGE、LTC、S、SUI、ZEC、BNB
  - 金(2)、主要な暗号資産(26)、話題の銘柄(7)、米国株・ETF の bStocks(15)、円建て(7)、BTC 建て(2:ETH/BTC、SOL/BTC)
  - 為替(2):USD/JPY(ドル円)と EUR/USDT(ユーロ/ドル)。すぐ呼び出せるよう、一覧のいちばん上に置いています
  - ドル円は Binance で取引されていないため、「BTC の円価格 ÷ BTC のドル(USDT)価格」をリアルタイムに計算した値です。本物の為替レートとは少しずれ、土日も動きます。出来高は参考値です
  - リストにあって載せていないもの:Binance で取引されていない TRIA・FLUID・FLR・LIGHTER・GFI・VVV と、指数・先物(DVOL、BTC 先物など)
  - 全銘柄の検索でも、人気の銘柄が上に出ます
- 時間足:1分/5分/15分/30分/1時間/4時間/日/週/月
- ドラッグで左右に移動、ホイール(スマホはピンチ)で拡大・縮小、ダブルクリックで元に戻す
- ペインの境目を上下にドラッグすると、高さを変えられます(境目をダブルクリックで元に戻す)
- キーボード:←→ で移動、↑↓ で拡大・縮小、End で最新の足へ
- スマホ:タップで十字線を表示、設定は画面下からのシートで開きます
- スマホでは、押す部品を指で押しやすい大きさ(40px 以上)にそろえています。横向きでは、注文画面が右側に出ます
- 初めて開いたときに、ポップアップ式の案内が出ます。画面の部品を1つずつ囲んで、9つの手順で説明します(あとからは「ツール → 使い方の案内」)。機能の一覧は「ツール → 使い方(一覧)」
- 操作マニュアル(`manual.html`)に、すべての機能の使い方を目的別にまとめています(「ツール → 操作マニュアル」)
- 移動平均線(MA)をローソク足に重ねて表示(本数・期間・色を変更可)
- RSI・MACD を追加可能(「インジケーター」メニューから)
- チャートの下に、表示する期間のボタン(1日・5日・1ヶ月・3ヶ月・6ヶ月・年初来・1年・5年・すべて)と時計。押すと、その期間に合った時間足に切りかえて、期間が画面に収まるように合わせる
- リプレイ(「ツール」→「リプレイ」):過去の足を選び、そこから1本ずつ、または自動(1・3・10本/秒)で再生する。リプレイ中は売買できない
- 重ねた線(移動平均線など)のいまの値を、線と同じ色のラベルで価格の目盛りに表示(パソコンのみ)
- RSI に、RSI をならした平均線を表示(初期設定は14本)
- 描画に「ものさし」(値幅・変化率・本数)と「文字」を追加。「線を隠す」「元に戻す(Ctrl + Z)」「全画面表示」も「ツール」から
- 「ツール」→「表示を切りかえ」で、ローソク足・平均足・ライン(終値)を切りかえられる
- ポジションの欄に「半分を決済」「損切りを建値へ」と、利確・損切りに届いたときの損益の目安を表示
- ポジションの欄に、建ててからの含み損益の推移を小さなグラフで表示。「成績を分析」には、取引ごとの損益の棒グラフを表示
- 約定が届くたびの更新では、価格・ローソク足・売買の判定をその場で行い、インジケーターの計算は、かかる時間に合わせて間をあける(インジケーターが多くても、価格の表示は止まらない)。隠したインジケーターは計算しない
- スマホでは、売り・買いのボタンが注文シートの下端に固定され、下のバーから2回のタップで決済できる
- レバレッジ取引(デモ):注文の欄で 1・2・3・5・10・20・50・100倍を選べる。1倍はこれまでどおりの現物の扱い
  - 証拠金 = 取引額 ÷ レバレッジ。ポジションごとに証拠金を分ける方式(分離マージン)で、損失はそのポジションの証拠金までで止まる
  - 強制決済の価格は、買いが 建値 ×(1 − 1/レバレッジ)÷(1 − 0.005)、売りが 建値 ×(1 + 1/レバレッジ)÷(1 + 0.005)。0.005 は維持証拠金の割合(0.5%)
  - 強制決済の価格は、ポジションの欄とチャートの線(オレンジの点線)に表示。ページを閉じていた間に届いた場合も、次に開いたときに強制決済する
  - 損切りを強制決済より遠くに置くことはできない(先に強制決済されるため)。含み益は、使える金額に数えない
  - 強制決済されると、そのポジションの証拠金をすべて失う(取引所と同じく、残った維持証拠金は戻らない)
  - 資金調達料は、実際の率を取り寄せられないため、基準の率 0.01%(買いが払い、売りが受け取る)が8時間ごと(UTC 0・8・16時)に続いたものとした目安で計算し、取引履歴に別の行で記録する。建玉の大きさによる維持証拠金の段階は、再現していない
- 注文の大きさは、金額でも数量でも入力できる(「数量で入力」で切りかえ)。取引履歴は、銘柄・勝ち負け・自動の約定で絞り込める
- 「ツール」→「売買ルールを試す」で、よく知られた6つのルール(移動平均の交差、長期の平均線の上下、RSI、MACD、ボリンジャーバンド、高値・安値の更新)を過去データで試算できる。「チャートに出す」を押すと、自作インジケーターとして追加され、数値や式を変えて試せる
- 「ツール」メニューから水平線・垂直線・トレンドライン・長方形・フィボナッチを引ける(タップで選択、ドラッグで移動、端の点で向きを変更、削除ボタンか Delete キーで削除)
- 線を置くとき、近くの始値・高値・安値・終値に自動で合わせる
- 「ツール」→「画像として保存」で、チャートを PNG 画像で保存
- 対数目盛り(「ツール」→「目盛り:ふつう / 対数」):価格の枠で、同じ%の値動きが同じ高さになる。線・利確/損切り・お知らせの線は同じ価格のまま。インジケーターの枠は、ふつうの目盛りのまま
- 銘柄の比較(「ツール」→「銘柄を重ねて比べる…」):もう1つの銘柄を、変化率(%)の線で重ねる。画面の左端の足を 0% として、見ている銘柄と同じ物差しで描く。凡例に名前と%を表示(× でやめる)。最新の足は約12秒ごとに取り直す(配信は増やさない)
- 描画ツールバー(幅 761px 以上では左に縦並び、スマホの縦向きではチャートの下に横並び):カーソル・水平線・垂直線・トレンドライン・長方形・フィボナッチ・ものさし・文字・価格のお知らせ・線を隠す/表示・元に戻す・線をすべて削除(2回押しで確定)。スマホでは出さない
- チャート上の売買ボタン(幅 761px 以上の画面):凡例の下に「売(売れる価格)」「買(買える価格)」を表示。2回押し(1回目で3秒だけ「もう一度押すと買います」)で、注文画面の金額・レバレッジ・利確/損切りを使って成行注文する。注文画面のボタンと同じ処理・同じ確認を通る。「ツール」→「チャート上の売買ボタン:表示 / 隠す」で消せる
- リンクの `ind`:`index.html?symbol=BTCUSDT&interval=1d&ind=rsi,macd` で開くと、その種類のインジケーターを出した状態にする(なければ追加、隠していれば表示。すでにあるものは消さない。知らない名前は無視、6個まで)。適用後、アドレスから `ind` を外す
- 価格はリアルタイムで更新(約定と気配値は、届いてから画面の1コマ=約16ミリ秒以内に反映。出来高も約定ごとに加算)、
  ポジションや指値注文があるほかの銘柄も、約定を受け取って 0.25 秒以内に損益と利確・損切りへ反映(10銘柄まで)、
  過去にさかのぼると古いデータを自動で読み足し
- 価格ラベルの下に、足が確定するまでの残り時間を表示
- 各インジケーター名の横の ⚙ で設定(パラメーター/スタイル/可視性)
- 設定はブラウザに保存されます

## デモトレード

仮想の資金で売買を練習できます(実際のお金は動きません)。

- 成行と指値の「買い」「売り(空売り)」、一部決済・全決済、利確・損切りの価格指定
- 損切りの価格を入れると、損切りで失う金額を表示。「資金の何%を失うか」から買う金額を逆算するボタンつき
- 注文にメモを残せる(履歴と CSV に出ます)
- ポジションを減らすために置いた指値は「決済用」として扱い、ポジションがなくなると自動で取り消します(残った指値が、反対向きの新しいポジションを作らないようにするため)
- 指値注文は、買いなら指値以下、売りなら指値以上の取引が1件でもあれば、指値ちょうどの価格で約定します(開いている間は約定ごと、閉じていた間は足の安値・高値で判定。その約定でできたポジションの利確・損切りは、次の時間帯から判定します)
- 「ツール」→「価格のお知らせ」で、決めた価格に届いたら知らせる線を置けます(注文はしません。その銘柄を表示している間だけ働きます)
- 資金は決済通貨ごと(USDT は 10,000、円は 100万円 など)。手数料 0.1%(片道)
- 建値・利確・損切り・指値の線と、売買した位置の印をチャートに表示。利確・損切り・指値の線はドラッグで動かせ、建値の線を引っぱると利確・損切りを新しく置けます
- 「成績を分析」:確定損益、勝率、プロフィットファクター、最大ドローダウン、資金の推移、銘柄ごとの成績。履歴は CSV で保存可能
- 成行は、板(上位5段)を注文の大きさの分だけ食っていった平均の価格で約定します(5段で足りない分は5段目より 0.1% 不利。板のない計算値の銘柄は最良の気配値)。注文の欄に、押す前の平均の約定価格の見込みを出します
- 損切り・強制決済は、届いた瞬間の決済できる価格(届いた約定の価格より有利にはしない)、利確・指値はその価格ちょうどで約定します。利確・損切りは、開いている間は約定を届いた順にたどって判定し、閉じていた間の分は次に開いたときにまとめて判定します(始値が損切りを越えていたら始値で決済)。一覧は操作マニュアルの「デモの約定のきまり」にあります
- 記録はブラウザ内に保存されます(別の端末やブラウザには引き継がれません)
- 抜け道への対策:
  - 価格を最新にできていない間(通信が止まっている、銘柄を切り替えた直後など)は、注文・決済・利確/損切りの変更ができません。鮮度は、端末の時計を変えても巻き戻らない経過時間で測ります
  - ページを閉じていた間(スリープや通信断も含む)に利確・損切りの価格に届いていた場合は、上の決まりの価格で決済します(長く閉じていた場合は、1時間足や日足の単位でしか調べられないため、記録する時刻はその足の終わりになります。同じ足の中で利確と損切りの両方に届いていたときは、どちらが先か分からないので、損切りが先だったとして扱います)。閉じていた間は、分の途中の端数(約定の記録)から 1分足・5分足・1時間足・日足まで、もれなく順に調べます。確認が済むまでは売買も条件の変更もできず、あとから条件を書き換えて過去の値動きに当てはめることはできません
  - 取引の時刻は、取引所の時計を基準に記録します
  - 使える金額は「評価額 − 保有分の時価」です。含み益を元手に買い増して、実質的にレバレッジをかけることはできません。価格を最新にできていない銘柄の含み益は、余力に数えません
  - 売り(ショート)の含み損で口座の評価額がゼロ以下になったら、強制的に決済します
  - 一瞬だけ利確・損切りの価格に届いてすぐ戻った場合も、届いたものとして決済します
  - 複数のタブで開いても、取引の内容はタブ間で同期します(古い内容での上書きはしません)
  - 取引所で取引できなくなった銘柄のポジションは、最後に取得できた価格で清算できます
- 成績の数え方:分けて決済しても、1つのポジションは1回の取引として数えます。勝ち負けは、買ったときと売ったときの両方の手数料を引いて判定します

PVT、PVO、相対出来高(RVOL)、Qスティック。

### 自分で作る

「インジケーター」メニューの「＋ 自分で作る」から、式を書くだけでオリジナルのインジケーターを作れます。

- 例:`ema(close, p1) - ema(close, p2)`(2本の平均線の差)。見本が8つ入っていて、そこから書きかえられます
- 使えるもの:価格(`open high low close volume hl2 hlc3 ohlc4`)、四則演算とかっこ、比較(`> < >= <= == !=`)、
  関数(`sma ema rma wma stdev highest lowest sum rsi roc change prev cum atr tr abs sqrt log max min pow if`
  `crossover crossunder and or not`)、
  あとから調整できる数値 `p1`〜`p3`
- 線は4本まで。下の枠に出す場合は、棒グラフと基準線も付けられます
- 合図は2つまで。条件の式(例:`crossover(ema(close, 10), ema(close, 30))`)が成り立った足に、▲ か ▼ を付けます
- 作っている途中から、いま開いているチャートの直近120本で描いた見本が出ます
- 合図のあるものは、設定画面の「過去データで試す」で、合図どおりに売買していた場合の成績を見られます
  (損益、持ち続けた場合との比較、勝率、プロフィットファクター、最大ドローダウン、資金の推移、売買の記録)。
  売買は合図が出た足の「次の足の始値」で行い、手数料 0.1% と、すべり(片道。最初は 0.05%、変えられる)を毎回不利な側に引きます。まだ確定していない足の合図は使いません。
  損切り・利確(%)も指定できます。1本の足の中で両方に届いた場合は、損切りが先だったとして計算します。損切りは窓を飛びこえたら始値で、利確は利確の価格ちょうどで手じまいます。
  持ち続けた場合も、同じ最初の足の始値と最後の足の終値で、同じ手数料・すべりを引いて比べます。
  同じ回数・向き・保有本数の売買をでたらめな時点で始めた 500 通り(決まった種の乱数)と比べ、成績が上から何%かも出します
- 設定画面の「合図が出たら知らせる」をオンにすると、ページを開いている間、足が確定して合図が出たときに画面へ表示します
  (許可した場合は、別のタブを見ているときにブラウザの通知も出します)。ページを閉じている間は知らせません
- メニューの ☆ を押すと「よく使う」に入り、いちばん上に並びます。自分で作ったものは ✎ から編集できます
- 式を間違えると、その場で理由が日本語で出ます。正しければ、いまの値が出ます
- 作ったものは「共有」で文字としてコピーでき、相手は「取り込む」に貼り付けて使えます
- 式は自前の読み取り器で計算します。`eval` などは使っておらず、決めた部品以外は動きません。
  保存されたもの・取り込んだものも、同じ検査を通ったものだけを使います(30個まで)

### 計算の確かめ

計算は `indicators.js` にまとめています。2026年11月に、全インジケーターを、TA-Lib・pandas-ta と、TradingView の定義を自分で書き直したものの3つと、実データ(BTC 日足、ETH 4時間足、金 日足、PEPE 日足、ユーロ 1時間足)で突き合わせました。

- ほとんどは、TradingView の定義と丸めの範囲で一致しました
- 食い違っていたので TradingView に合わせたもの:ALMA(重心を切り捨てていた)、TRIX(TradingView の目盛りに合わせ、約100倍に)、コナーズRSI(同じ値を数える扱い)、マクギニー・ダイナミック(最初の値)、スーパートレンド(最初の向き)、ウィリアムズ・フラクタル(平らな山・谷)、オーサム・オシレーターの色
- 値動きや出来高がまったくないときに、50 や 0 などの仮の値を出していたものは、空けるようにしました(TradingView と同じ)
- あえて残した違い
  - パラボリック SAR:TA-Lib と一致。TradingView の細かな計算は確かめられなかったため、変えていません
  - 一目均衡表:TradingView は「26本」を25本ずらして描きます。設定の「ずらす本数」の意味が変わるため、変えていません
  - BOP:高値と安値が同じ足は 0(TA-Lib と同じ。TradingView は空ける)
- 独立に確かめられていないもの:RCI(比べられる基準がない)、TradingView の計算の一部(記憶にもとづく書き直しのため)

### 過去データでの試算の確かめ

`backtest` を、同じきまりで別に書いた Python の計算と、4種類の実データ × 3つの売買ルールで比べ、112通り・63,738件の取引がすべて一致しました。このときに見つかった、利確が窓で有利に約定していた点、売りの強制決済の判定順、「持ち続けた場合」の手数料の数え方は直しています。

## 安全のための設定

- 外部のスクリプトは一切読み込みません。通信先は Binance の公開 API だけに制限しています(Content-Security-Policy)
- ブラウザに保存した設定や取引データは、読み込むときに形を確かめ、想定外の値は捨てます
- API キーや個人情報は扱いません。デモトレードの記録は、そのブラウザの中だけにあります
- 公開ページは、他のサイトの中に埋め込んで表示できないようにしています
- 公開処理(GitHub Actions)で使う部品は、コミット番号で固定しています
- インジケーター(30個)、線(1銘柄200本)、追加銘柄(100個)には上限があります

## データについて

- 価格は Binance の公開 API から取得します(API キー不要)。
- 取得できない環境では、乱数で作った「デモデータ」を表示します。
  右上に「デモデータ」と出ているときは、実際の価格ではありません。
- 「金」は金に連動するトークン PAXG の価格で、金の現物価格そのものではありません。

## 写真(TradingView)と合わせた点

- 2日足の区切り方(2025-03-08 が足の始まりになる並び)
- `Volume (c-c) Only` は青緑、`Volume/MA with Enhanced Histogram` は緑の配色
- 山と谷に付く丸印(スタイルタブでオン/オフ)

## インジケーターの計算

`Volume (c-c) Only` と `Volume/MA with Enhanced Histogram` は、
設定項目の名前をもとに独自に組んだ計算式です(`app.js` の `computeCC`)。
同名の既存スクリプトと数値が一致することは保証しません。

1. 前の足からの値動きを `Normalize by` の基準で割り、-1〜+1 にそろえる
2. `Wick Weight` の割合で「足の中での終値の位置」を混ぜる
3. それを出来高に掛ける
4. `Aggregation` と `Moving Average Length` でならす
5. その値の単純移動平均(SMA)を出し、上か下かで色を変える
