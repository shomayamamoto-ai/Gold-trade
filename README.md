# Gold Trade Chart

ブラウザだけで動く、チャート表示サイトです。
ローソク足・出来高に加えて、出来高系インジケーターを2種類表示できます。

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド不要)。

- 銘柄:金(PAXG/USDT)、BTC、ETH、XRP、SOL、XRP/JPY、PEPE。一覧の「+ 銘柄を追加…」から、Binance の好きな通貨ペアを追加可能
- 時間足:15分/1時間/4時間/日/2日/週
- ドラッグで左右に移動、ホイール(スマホはピンチ)で拡大・縮小、ダブルクリックで元に戻す
- ペインの境目を上下にドラッグすると、高さを変えられます(境目をダブルクリックで元に戻す)
- キーボード:←→ で移動、↑↓ で拡大・縮小、End で最新の足へ
- スマホ:タップで十字線を表示、設定は画面下からのシートで開きます
- 移動平均線(MA)をローソク足に重ねて表示(本数・期間・色を変更可)
- RSI・MACD を追加可能(「インジケーター」メニューから)
- 「ツール」メニューから水平線・トレンドラインを引ける(タップで選択、ドラッグで移動、端の点で向きを変更、削除ボタンか Delete キーで削除)
- 線を置くとき、近くの始値・高値・安値・終値に自動で合わせる
- 「ツール」→「画像として保存」で、チャートを PNG 画像で保存
- 価格はリアルタイムで更新、過去にさかのぼると古いデータを自動で読み足し
- 価格ラベルの下に、足が確定するまでの残り時間を表示
- 各インジケーター名の横の ⚙ で設定(パラメーター/スタイル/可視性)
- 設定はブラウザに保存されます

## データについて

- 価格は Binance の公開 API から取得します(API キー不要)。
- 取得できない環境では、乱数で作った「デモデータ」を表示します。
  右上に「デモデータ」と出ているときは、実際の価格ではありません。
- 「金」は金に連動するトークン PAXG の価格で、金の現物価格そのものではありません。

## 写真(TradingView)と合わせた点

- 2日足の区切り方(2025-03-08 が足の始まりになる並び)
- `Volume (c-c) Only` は青緑、`Volume/MA with Enhanced Histogram` は緑の配色
- 山と谷に付く丸印(スタイルタブでオン/オフ)

## インジケーターの計算

`Volume (c-c) Only` と `Volume/MA with Enhanced Histogram` は、
設定項目の名前をもとに独自に組んだ計算式です(`app.js` の `computeCC`)。
同名の既存スクリプトと数値が一致することは保証しません。

1. 前の足からの値動きを `Normalize by` の基準で割り、-1〜+1 にそろえる
2. `Wick Weight` の割合で「足の中での終値の位置」を混ぜる
3. それを出来高に掛ける
4. `Aggregation` と `Moving Average Length` でならす
5. その値の単純移動平均(SMA)を出し、上か下かで色を変える
