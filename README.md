# Gold Trade Chart

ブラウザだけで動く、チャート表示サイトです。
ローソク足・出来高に加えて、出来高系インジケーターを2種類表示できます。

## 公開ページ

GitHub Pages で公開する設定になっています(Settings → Pages → Source を「GitHub Actions」にすると有効になります)。

- チャート: https://shomayamamoto-ai.github.io/Gold-trade/
- 教科書: https://shomayamamoto-ai.github.io/Gold-trade/guide.html

## 使い方

`index.html` をブラウザで開くだけで動きます(ビルド不要)。教科書は `guide.html` です。

- 銘柄:金(PAXG/USDT)、BTC、ETH、XRP、SOL、XRP/JPY、PEPE。一覧の「+ 銘柄を追加…」から、Binance の好きな通貨ペアを追加・削除可能
- 時間足:1分/5分/15分/30分/1時間/4時間/日/週/月
- ドラッグで左右に移動、ホイール(スマホはピンチ)で拡大・縮小、ダブルクリックで元に戻す
- ペインの境目を上下にドラッグすると、高さを変えられます(境目をダブルクリックで元に戻す)
- キーボード:←→ で移動、↑↓ で拡大・縮小、End で最新の足へ
- スマホ:タップで十字線を表示、設定は画面下からのシートで開きます
- スマホでは、押す部品を指で押しやすい大きさ(40px 以上)にそろえています。横向きでは、注文画面が右側に出ます
- 初めて開いたときに、ポップアップ式の案内が出ます。画面の部品を1つずつ囲んで、9つの手順で説明します(あとからは「ツール → 使い方の案内」)。機能の一覧は「ツール → 使い方(一覧)」
- 操作マニュアル(`manual.html`)に、すべての機能の使い方を目的別にまとめています(「ツール → 操作マニュアル」)
- 移動平均線(MA)をローソク足に重ねて表示(本数・期間・色を変更可)
- RSI・MACD を追加可能(「インジケーター」メニューから)
- 「ツール」→「表示を切りかえ」で、ローソク足・平均足・ライン(終値)を切りかえられる
- ポジションの欄に「半分を決済」「損切りを建値へ」と、利確・損切りに届いたときの損益の目安を表示
- ポジションの欄に、建ててからの含み損益の推移を小さなグラフで表示。「成績を分析」には、取引ごとの損益の棒グラフを表示
- 約定が届くたびの更新では、価格・ローソク足・売買の判定をその場で行い、インジケーターの計算は、かかる時間に合わせて間をあける(インジケーターが多くても、価格の表示は止まらない)。隠したインジケーターは計算しない
- スマホでは、売り・買いのボタンが注文シートの下端に固定され、下のバーから2回のタップで決済できる
- 注文の大きさは、金額でも数量でも入力できる(「数量で入力」で切りかえ)。取引履歴は、銘柄・勝ち負け・自動の約定で絞り込める
- 「ツール」→「売買ルールを試す」で、よく知られた6つのルール(移動平均の交差、長期の平均線の上下、RSI、MACD、ボリンジャーバンド、高値・安値の更新)を過去データで試算できる。「チャートに出す」を押すと、自作インジケーターとして追加され、数値や式を変えて試せる
- 「ツール」メニューから水平線・垂直線・トレンドライン・長方形・フィボナッチを引ける(タップで選択、ドラッグで移動、端の点で向きを変更、削除ボタンか Delete キーで削除)
- 線を置くとき、近くの始値・高値・安値・終値に自動で合わせる
- 「ツール」→「画像として保存」で、チャートを PNG 画像で保存
- 価格はリアルタイムで更新(約定と気配値は、届いてから画面の1コマ=約16ミリ秒以内に反映。出来高も約定ごとに加算)、
  ポジションや指値注文があるほかの銘柄も、約定を受け取って 0.25 秒以内に損益と利確・損切りへ反映(10銘柄まで)、
  過去にさかのぼると古いデータを自動で読み足し
- 価格ラベルの下に、足が確定するまでの残り時間を表示
- 各インジケーター名の横の ⚙ で設定(パラメーター/スタイル/可視性)
- 設定はブラウザに保存されます

## デモトレード

仮想の資金で売買を練習できます(実際のお金は動きません)。

- 成行と指値の「買い」「売り(空売り)」、一部決済・全決済、利確・損切りの価格指定
- 損切りの価格を入れると、損切りで失う金額を表示。「資金の何%を失うか」から買う金額を逆算するボタンつき
- 注文にメモを残せる(履歴と CSV に出ます)
- ポジションを減らすために置いた指値は「決済用」として扱い、ポジションがなくなると自動で取り消します(残った指値が、反対向きの新しいポジションを作らないようにするため)
- 指値注文の約定価格は、指値か、それより有利な気配値です。ページを閉じていた間に指値に届いていた場合は、次に開いたときに、届いた時間帯の価格で約定します(その約定でできたポジションの利確・損切りは、次の時間帯から判定します)
- 「ツール」→「価格のお知らせ」で、決めた価格に届いたら知らせる線を置けます(注文はしません。その銘柄を表示している間だけ働きます)
- 資金は決済通貨ごと(USDT は 10,000、円は 100万円 など)。レバレッジなし、手数料 0.1%
- 建値・利確・損切り・指値の線と、売買した位置の印をチャートに表示。利確・損切り・指値の線はドラッグで動かせ、建値の線を引っぱると利確・損切りを新しく置けます
- 「成績を分析」:確定損益、勝率、プロフィットファクター、最大ドローダウン、資金の推移、銘柄ごとの成績。履歴は CSV で保存可能
- 約定は気配値(買いは売り注文の最良価格、売りは買い注文の最良価格)で即時に行う簡易計算です。利確・損切りは、開いている間は約定ごとに、閉じていた間の分は次に開いたときにまとめて判定します
- 記録はブラウザ内に保存されます(別の端末やブラウザには引き継がれません)
- 抜け道への対策:
  - 価格を最新にできていない間(通信が止まっている、銘柄を切り替えた直後など)は、注文・決済・利確/損切りの変更ができません。鮮度は、端末の時計を変えても巻き戻らない経過時間で測ります
  - ページを閉じていた間(スリープや通信断も含む)に利確・損切りの価格に届いていた場合は、届いた時点の価格で決済します(長く閉じていた場合は、1時間足や日足の単位でしか調べられないため、記録する時刻はその足の終わりになります。同じ足の中で利確と損切りの両方に届いていたときは、どちらが先か分からないので、損切りが先だったとして扱います)。閉じていた間は、分の途中の端数(約定の記録)から 1分足・5分足・1時間足・日足まで、もれなく順に調べます。確認が済むまでは売買も条件の変更もできず、あとから条件を書き換えて過去の値動きに当てはめることはできません
  - 取引の時刻は、取引所の時計を基準に記録します
  - 使える金額は「評価額 − 保有分の時価」です。含み益を元手に買い増して、実質的にレバレッジをかけることはできません。価格を最新にできていない銘柄の含み益は、余力に数えません
  - 売り(ショート)の含み損で口座の評価額がゼロ以下になったら、強制的に決済します
  - 一瞬だけ利確・損切りの価格に届いてすぐ戻った場合も、届いたものとして決済します
  - 複数のタブで開いても、取引の内容はタブ間で同期します(古い内容での上書きはしません)
  - 取引所で取引できなくなった銘柄のポジションは、最後に取得できた価格で清算できます
- 成績の数え方:分けて決済しても、1つのポジションは1回の取引として数えます。勝ち負けは、買ったときと売ったときの両方の手数料を引いて判定します

## インジケーター

「インジケーター」メニューから57種類を追加できます(名前で検索可)。自分で作ることもできます。

- トレンド:移動平均線(SMA/EMA/RMA/WMA/HMA/DEMA/TEMA/KAMA/VWMA)、一目均衡表、パラボリック SAR、スーパートレンド、
  ドンチャンチャネル、ADX/DMI、アルーン、アルーン・オシレーター、エンベロープ、線形回帰線、線形回帰の傾き、
  アリゲーター、ボルテックス、エルダーレイ
- オシレーター:RSI、MACD、ストキャスティクス、ストキャスティクス RSI、CCI、ウィリアムズ %R、ROC、モメンタム、
  オーサム・オシレーター、TRIX、PPO、CMO、アルティメット・オシレーター、DPO、フィッシャー変換、コポック曲線、
  移動平均乖離率、サイコロジカルライン、RCI、Zスコア
- ボラティリティ:ボリンジャーバンド、ケルトナーチャネル、ATR、ATR%、ボリンジャーバンド幅、ボリンジャー %B、
  ヒストリカル・ボラティリティ、標準偏差、チョピネス指数、マス・インデックス、シャンデリア・エグジット
- 出来高:出来高と移動平均、VWAP、OBV、A/D ライン、CMF、MFI、BOP、チャイキン・オシレーター、フォース・インデックス、
  EOM、Volume (c-c) Only、Volume/MA with Enhanced Histogram

### 自分で作る

「インジケーター」メニューの「＋ 自分で作る」から、式を書くだけでオリジナルのインジケーターを作れます。

- 例:`ema(close, p1) - ema(close, p2)`(2本の平均線の差)。見本が8つ入っていて、そこから書きかえられます
- 使えるもの:価格(`open high low close volume hl2 hlc3 ohlc4`)、四則演算とかっこ、比較(`> < >= <= == !=`)、
  関数(`sma ema rma wma stdev highest lowest sum rsi roc change prev cum atr tr abs sqrt log max min pow if`
  `crossover crossunder and or not`)、
  あとから調整できる数値 `p1`〜`p3`
- 線は4本まで。下の枠に出す場合は、棒グラフと基準線も付けられます
- 合図は2つまで。条件の式(例:`crossover(ema(close, 10), ema(close, 30))`)が成り立った足に、▲ か ▼ を付けます
- 作っている途中から、いま開いているチャートの直近120本で描いた見本が出ます
- 合図のあるものは、設定画面の「過去データで試す」で、合図どおりに売買していた場合の成績を見られます
  (損益、持ち続けた場合との比較、勝率、プロフィットファクター、最大ドローダウン、資金の推移、売買の記録)。
  売買は合図が出た足の「次の足の始値」で行い、手数料 0.1% を毎回引きます。まだ確定していない足の合図は使いません。
  損切り・利確(%)も指定できます。1本の足の中で両方に届いた場合は、損切りが先だったとして計算します
- 設定画面の「合図が出たら知らせる」をオンにすると、ページを開いている間、足が確定して合図が出たときに画面へ表示します
  (許可した場合は、別のタブを見ているときにブラウザの通知も出します)。ページを閉じている間は知らせません
- メニューの ☆ を押すと「よく使う」に入り、いちばん上に並びます。自分で作ったものは ✎ から編集できます
- 式を間違えると、その場で理由が日本語で出ます。正しければ、いまの値が出ます
- 作ったものは「共有」で文字としてコピーでき、相手は「取り込む」に貼り付けて使えます
- 式は自前の読み取り器で計算します。`eval` などは使っておらず、決めた部品以外は動きません。
  保存されたもの・取り込んだものも、同じ検査を通ったものだけを使います(30個まで)

### 計算の確かめ

計算は `indicators.js` にまとめています。実際の BTC の日足(約3,000本)で、ほかの計算ライブラリと数値を突き合わせました。

- TA-Lib と一致(誤差は丸めの範囲):インジケーター30種類と、移動平均の DEMA・TEMA・KAMA
- pandas-ta または pandas での計算と一致:HMA、VWMA、ボルテックス、チョピネス指数、フィッシャー変換、コポック曲線、
  DPO、Zスコア、EOM、フォース・インデックス、マス・インデックス、サイコロジカルライン、移動平均乖離率、CMO、
  エルダーレイ、ボリンジャーバンド幅、RCI、エンベロープ、シャンデリア・エグジット、ヒストリカル・ボラティリティ
- 一致しないもの
  - スーパートレンド:pandas-ta とは約3%の足で値が違います。向きが切り替わる足での帯の扱いが違うためです
  - CMO:TA-Lib とは一致しません(TA-Lib はならし方が別)。pandas-ta とは一致します
- 突き合わせていないもの:VWAP、出来高と移動平均、アリゲーター、Volume (c-c) 系の2つ

## 安全のための設定

- 外部のスクリプトは一切読み込みません。通信先は Binance の公開 API だけに制限しています(Content-Security-Policy)
- ブラウザに保存した設定や取引データは、読み込むときに形を確かめ、想定外の値は捨てます
- API キーや個人情報は扱いません。デモトレードの記録は、そのブラウザの中だけにあります
- 公開ページは、他のサイトの中に埋め込んで表示できないようにしています
- 公開処理(GitHub Actions)で使う部品は、コミット番号で固定しています
- インジケーター(30個)、線(1銘柄200本)、追加銘柄(100個)には上限があります

## データについて

- 価格は Binance の公開 API から取得します(API キー不要)。
- 取得できない環境では、乱数で作った「デモデータ」を表示します。
  右上に「デモデータ」と出ているときは、実際の価格ではありません。
- 「金」は金に連動するトークン PAXG の価格で、金の現物価格そのものではありません。

## 写真(TradingView)と合わせた点

- 2日足の区切り方(2025-03-08 が足の始まりになる並び)
- `Volume (c-c) Only` は青緑、`Volume/MA with Enhanced Histogram` は緑の配色
- 山と谷に付く丸印(スタイルタブでオン/オフ)

## インジケーターの計算

`Volume (c-c) Only` と `Volume/MA with Enhanced Histogram` は、
設定項目の名前をもとに独自に組んだ計算式です(`app.js` の `computeCC`)。
同名の既存スクリプトと数値が一致することは保証しません。

1. 前の足からの値動きを `Normalize by` の基準で割り、-1〜+1 にそろえる
2. `Wick Weight` の割合で「足の中での終値の位置」を混ぜる
3. それを出来高に掛ける
4. `Aggregation` と `Moving Average Length` でならす
5. その値の単純移動平均(SMA)を出し、上か下かで色を変える
