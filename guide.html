第1章チャートの基本

ローソク足は「4つの価格」を1本にまとめたもの

常識 チャートに並んでいる棒を「ローソク足」と呼びます。 1本が、ある期間(たとえば1日)の値動きを表しています。 1本の中には、始値・高値・安値・終値の4つの価格が入っています。

  • 実体が長い:その期間に、一方向へ強く動いた。
  • ヒゲが長い:いったんそこまで動いたが、押し戻された。
  • 実体が短くヒゲも短い:ほとんど動かなかった(迷っている状態)。

時間足 — 同じ値動きを、どの細かさで見るか

常識 1本の足が表す期間を「時間足」と呼びます。15分足なら1本が15分、日足なら1本が1日です。短い時間足ほど細かい動きが見えますが、だましの動き(ノイズ)も増えます。

考え方 初めのうちは、長い足(日足)で大きな流れを確認してから、短い足で売買の場所を探す 順番がおすすめです。短い足だけを見ていると、大きな下げの途中の小さな上げを「上昇」と勘違いしやすいためです。

出来高 — その値動きに、どれだけの人が参加したか

常識 出来高は、その期間に売買された量です。このサイトでは、ローソク足の下の棒で表示しています。同じ値上がりでも、出来高が多ければ「多くの人が参加した動き」、少なければ「少人数で動いただけ」と読めます。

通貨ペアの読み方

常識 「BTC/USDT」は、左の通貨(BTC)を、右の通貨(USDT)でいくらで買えるかを表します。右側を「決済通貨」と呼びます。「XRP/JPY」なら、XRP 1枚が何円かを表します。

常識 USDT や USDC は、価格が米ドルとほぼ同じになるよう設計された暗号資産で、「ステーブルコイン」と呼ばれます。ただし、常に1ドルちょうどである保証はありません。

第2章銘柄の特徴

このサイトに最初から入っている銘柄を中心に、成り立ちと値動きのくせをまとめます。「値動きの傾向」は時期によって変わるので、いまもそうだとは限りません。

銘柄ひとことで言うと発行の上限値動きの大きさ(目安)
金 (PAXG)金の現物に連動するトークン裏付けの金の量による小さい
BTC最初の暗号資産。市場全体の中心2,100万枚中くらい
ETHアプリが動く土台の通貨上限なし中〜大
XRP送金を速く安くするための通貨1,000億枚(発行済み)大きい
SOL処理の速さを重視した土台の通貨上限なし大きい
DOGEジョークから生まれた通貨上限なしとても大きい
PEPEネットの人気で動くミームコイン約420.69兆枚きわめて大きい

考え方 「値動きの大きさ」の列は、筆者による大まかな目安です。数字で測ったものではありません。実際の大きさは、このサイトで日足を並べて見比べると実感できます。

金 — PAXG/USDT

事実 PAXG(パックス・ゴールド)は、米国の Paxos 社が発行するトークンです。 1 PAXG が、ロンドンの金庫に保管された金 1 トロイオンスに対応します。 2019年9月に、ニューヨーク州金融サービス局(NYDFS)の承認を受けて始まりました。[1]

常識 1 トロイオンスは約 31.1 グラムです。金の国際価格は、ふつうこの単位あたりの米ドルで表します。

値動きのくせ

  • 常識金は、株や暗号資産が大きく下がる場面で買われやすい「安全資産」と見なされることがあります。ただし、必ずそう動くわけではありません。
  • 考え方暗号資産の中では値動きが小さいため、練習の最初の銘柄に向いています。一方で、短期で大きな利益をねらうのには向きません。

注意点

  • 考え方PAXG の価格は金の現物価格そのものではなく、わずかにずれることがあります。
  • 考え方金そのものではなく「発行会社が金と引き換える約束をしたトークン」なので、発行会社を信用することが前提になります。
  • 考え方週末は金の現物市場が閉まっていますが、PAXG は24時間取引されます。週末は参加者が少なく、値動きが不規則になることがあります。

ビットコイン — BTC

事実 発行の上限は約2,100万枚です。新しく発行される量は、21万ブロックごと(およそ4年ごと)に半分になります。これを「半減期」と呼びます。ブロックは平均10分に1つ作られ、新規発行は2140年ごろに終わる見込みです。[2]

値動きのくせ

  • 常識暗号資産の中で取引量が最も多く、市場全体の方向を決める存在です。BTC が大きく下がると、ほかの銘柄もつられて下がることが多くあります。
  • 考え方ほかの銘柄を取引するときも、先に BTC の日足を見て「市場全体が上向きか下向きか」を確かめる習慣が役に立ちます。

注意点

  • 考え方「半減期のあとは上がる」とよく言われますが、過去の回数が少なく、今後も同じになる根拠としては弱いものです。

イーサリアム — ETH

事実 2022年9月15日の「マージ(The Merge)」という更新で、取引を承認するしくみがプルーフ・オブ・ワークからプルーフ・オブ・ステークに切り替わりました。これにより、消費電力は約99.95%減ったとされています。[3]

常識 イーサリアムは、通貨のやり取りだけでなく、プログラム(スマートコントラクト)を動かせる土台です。ほかの多くのトークン(PAXG や PEPE も含む)が、この土台の上で発行されています。

値動きのくせ

  • 常識BTC と同じ方向に動くことが多い一方、動く幅は BTC より大きくなりがちです。

エックスアールピー — XRP

事実 XRP は「XRP レジャー」という台帳で使われる通貨です。始まった時点で1,000億枚がすべて発行済みで、あとから増えることはありません。取引は3〜5秒ほどで確定します。発行分のうち約800億枚は、のちの Ripple 社に渡されました。[4]

値動きのくせ

  • 考え方ニュース(規制、裁判、提携の発表など)に強く反応し、短時間で急に動くことがあります。
  • 常識日本でも取引する人が多い銘柄で、円建て(XRP/JPY)でも取引されています。

注意点

  • 考え方特定の会社が大量に保有している点は、「売りに出されると値下がりの原因になり得る」という見方があります。

ソラナ — SOL

事実 ソラナは、取引の順番を記録する「プルーフ・オブ・ヒストリー」という時計のようなしくみと、プルーフ・オブ・ステークを組み合わせています。前者が順番を、後者が承認者の選出と安全性を受け持ちます。[5]

値動きのくせ

  • 考え方上げるときも下げるときも幅が大きく、BTC や ETH より値動きが荒い傾向があります。

注意点

  • 常識過去にネットワークが一時的に止まる障害が何度か起きています。障害の間は売買できないことがあります。

ドージコイン — DOGE

事実 2013年12月6日に、ビリー・マーカス氏とジャクソン・パーマー氏が、ビットコインへの風刺(ジョーク)として始めた通貨です。[6]

常識 発行枚数に上限がなく、毎年ほぼ一定の量が新しく発行され続けます。

値動きのくせ

  • 考え方技術的な進歩よりも、著名人の発言や SNS での話題で大きく動く傾向があります。

ペペ — PEPE

事実 2023年4月に、イーサリアム上のトークン(ERC-20)として始まったミームコインです。発行上限は約420.69兆枚です。[7]

値動きのくせ

  • 常識ミームコインは、実用的な使い道よりも人気や話題で価格が決まります。1日で数十%動くことも珍しくありません。
  • 常識1枚の価格が非常に小さい(小数点以下に 0 が並ぶ)ため、価格の「安さ」と割安さは関係がありません。

注意点

  • 考え方練習には使えますが、実際のお金で扱うなら、失ってもよい少額にとどめるのが無難です。

ほかの銘柄を調べるとき —このサイトでは、銘柄の一覧から Binance で取引中のすべての通貨ペアを選べます。知らない銘柄は、次の4点を先に確かめてください。

  1. 何のために作られた通貨か(使い道)。
  2. 発行枚数に上限があるか。特定の人や会社が大量に持っていないか。
  3. 出来高は十分か(少ないと、思った価格で売買できません)。
  4. 日足で見て、1日にどのくらい動く銘柄か。

第3章インジケーター

常識 インジケーターは、価格や出来高を計算し直して、見やすくした補助の線やグラフです。どれも過去のデータから計算しているので、未来を言い当てる道具ではありません。「いま何が起きているかを整理する道具」として使います。

移動平均線(MA)

何を見るか

常識直近の何本かの終値を平均し、線でつないだものです。細かい上下をならして、流れ(トレンド)の向きを見ます。

読み方

  • 常識線が右上がりで、価格が線より上にある → 上向きの流れ。
  • 常識線が右下がりで、価格が線より下にある → 下向きの流れ。
  • 常識短い期間の線が長い期間の線を下から上に抜けることを「ゴールデンクロス」、逆を「デッドクロス」と呼びます。

種類

  • 常識SMA(単純):全部の足を同じ重さで平均します。なめらかですが反応は遅めです。
  • 常識EMA(指数):新しい足ほど重く見ます。反応が速い分、だましも増えます。

弱点

  • 常識平均なので、必ず実際の値動きより遅れます。
  • 常識価格が横ばい(レンジ)のときは、線の上下を何度も行き来して役に立ちません。

考え方期間は 20、50、200 がよく使われます。このサイトの初期値は 20 です。「正解の期間」はなく、多くの人が見ている期間ほど意識されやすい、という程度に考えてください。

RSI

何を見るか

事実 J・ウェルズ・ワイルダー氏が1978年に発表した指標です。[8] 常識 直近の「上げ幅の平均」と「下げ幅の平均」を比べ、0〜100 の数字にします。上げ下げの勢いのかたよりを見ます。

読み方

  • 常識70 より上 → 短期的に買われすぎの目安。30 より下 → 売られすぎの目安。期間は 14 が一般的です。
  • 常識価格は高値を更新しているのに RSI の山は低くなっている状態を「ダイバージェンス」と呼び、勢いの弱まりのサインとされます。

弱点

  • 常識強い上昇の最中は、70 より上に張り付いたまま上がり続けます。「70 を超えたから売り」は、強い流れの中では負けやすい使い方です。

考え方RSI は、横ばいの相場で力を発揮します。流れがはっきりしているときは、移動平均線で向きを確かめたうえで補助として使うのがよいでしょう。

MACD

何を見るか

事実 ジェラルド・アペル氏が1970年代の終わりごろに考案した指標です。短期(12)と長期(26)の EMA の差を取り、その差の EMA(9)を「シグナル」とします。[8] 常識 流れの向きと、その強まり・弱まりを見ます。

読み方

  • 常識MACD の線がシグナルを下から上に抜ける → 上向きの勢いが出てきた。逆は下向き。
  • 常識棒グラフ(MACD とシグナルの差)が縮んできた → 勢いが弱まってきた。
  • 常識MACD が 0 より上か下かで、大きな流れの向きを見ます。

弱点

  • 常識移動平均から作るので、やはり遅れます。横ばいの相場では、交差が何度も出てだまされます。

出来高

読み方

  • 常識価格が上がり、出来高も増えている → その上昇に多くの人が参加している。
  • 常識価格は上がっているのに、出来高が減っている → 上昇の勢いが弱まっている可能性。
  • 常識長く横ばいだった価格が、大きな出来高をともなって動いた → 新しい流れの始まりのことがある。

弱点

  • 考え方このサイトの出来高は Binance の分だけです。ほかの取引所の売買は含みません。

Volume (c-c) Only / Volume/MA with Enhanced Histogram

考え方 この2つは、設定項目の名前をもとに、このサイトが独自に組んだ計算です。 TradingView にある同じ名前のスクリプトとは、数値が一致しません。以下は「このサイトでの計算」の説明です。

何を見るか

出来高に「値動きの向きと強さ」を掛け合わせ、買いと売りのどちらに出来高が集まっているかを見ようとするものです。

計算の流れ

  1. 前の足の終値から今の足の終値への動きを、その足の値幅で割り、-1〜+1 の数字にする。
  2. その数字に出来高を掛ける。大きく上げて出来高も多ければ大きなプラス、逆なら大きなマイナス。
  3. 14本分をならして、なめらかにする。
  4. さらにその平均線を出し、平均より上か下かで色の濃さを変える。

読み方

  • 0 より上 → 買いに出来高が集まっている。0 より下 → 売りに集まっている。
  • 薄い色 → 自分の平均より上(勢いが増している)。濃い色 → 平均より下(勢いが弱まっている)。
  • 丸印は、山や谷(前後より高い・低い点)です。

弱点

  • ならしているので、価格の動きより遅れます。
  • この計算が売買に役立つかどうかは、検証していません。ほかの指標と見比べながら使ってください。

インジケーターを使うときの心得 考え方

  • 数を増やしても精度は上がりません。似た計算の指標を重ねても、同じことを別の形で見ているだけです。「流れを見るもの(MA)」と「勢いを見るもの(RSI か MACD)」を1つずつ、で十分です。
  • 設定を成績が良くなるまでいじるのは危険です。過去にたまたま合っただけの設定になり、これからの相場では通用しないことが多くあります。

第4章トレードの手法

常識 相場の状態は、大きく分けて「一方向に進んでいる(トレンド)」と「一定の幅を行き来している(レンジ)」の2つです。手法はどちらかの状態に合わせて作られているので、いまの相場がどちらかを先に判断することが出発点になります。

保有する時間による分類

呼び名保有する時間よく見る時間足向いている人
スキャルピング数秒〜数分1分・5分画面に張り付ける人。手数料の影響が大きく、初心者には不向き
デイトレード数分〜1日15分・1時間日中に時間が取れる人
スイングトレード数日〜数週間4時間・日足1日に数回だけ見られる人。最初の練習におすすめ
長期保有数か月〜日足・週足細かい値動きを気にしたくない人

考え方 時間が短いほど、売買の回数が増えて手数料がかさみます。たとえば手数料が片道 0.1% なら、買って売るだけで 0.2% かかります。[9] ねらう値幅が 0.5% の取引では、その4割が手数料で消える計算です。

手法1:流れに乗る(トレンドフォロー)

常識上向きの流れのときに買い、流れが続くかぎり持ち続ける方法です。「順張り」とも呼びます。

このサイトでの手順(買いの例)

  1. 日足を開き、移動平均線(期間 20)が右上がりで、価格が線より上にあることを確かめる。
  2. 価格がいったん下がって、移動平均線の近くまで戻るのを待つ(これを「押し目」と呼びます)。
  3. そこから再び上がり始めた足(緑の足)が出たら買う。
  4. 損切りは、直近の安値の少し下に置く。
  5. 利確は、損切りまでの幅の2倍以上の位置に置く。または、価格が移動平均線を下に抜けたら決済する。

強みと弱み

  • 常識強み:大きな流れが出たときに、大きな利益をねらえます。
  • 常識弱み:横ばいの相場では、小さな損切りが続きます。勝率は低めになりがちで、「小さく負けて、たまに大きく勝つ」形になります。

手法2:行き来の幅で売買する(レンジ取引)

常識価格が一定の幅を行き来しているときに、下の端で買い、上の端で売る方法です。「逆張り」の一種です。

このサイトでの手順(買いの例)

  1. 価格が何度も止められている高値と安値を探し、「ツール」→「水平線」でそれぞれに線を引く。
  2. 移動平均線がほぼ横ばいであることを確かめる(傾いているならレンジではありません)。
  3. 価格が下の線に近づき、RSI が 30 付近まで下がったら買う。
  4. 損切りは、下の線の少し下に置く。
  5. 利確は、上の線の少し手前に置く。

強みと弱み

  • 常識強み:横ばいの相場は期間が長く、機会が多くあります。勝率は高めになりがちです。
  • 常識弱み:レンジを抜けて一方向に走り出すと、1回で大きく負けます。損切りを必ず置くことが前提です。

手法3:抜けた方向に乗る(ブレイクアウト)

常識長く止められていた高値(または安値)を抜けた瞬間に、その方向へ乗る方法です。

このサイトでの手順(買いの例)

  1. 何度も止められている高値に、水平線を引く。
  2. 足の終値がその線を上に抜けるのを待つ(ヒゲで一瞬抜けただけでは買いません)。
  3. 抜けた足の出来高が、それまでより明らかに多いことを確かめる。
  4. 買う。損切りは、抜けた線の少し下に置く。

強みと弱み

  • 常識強み:新しい流れの始まりに乗れることがあります。
  • 常識弱み:抜けたように見えてすぐ戻る「だまし」が多くあります。出来高の確認は、だましを減らすための工夫です。

「売り」から入る取引について 常識

このサイトのデモトレードでは、持っていないものを先に売り、下がってから買い戻す「売り(ショート)」も練習できます。実際の取引でこれを行うには、信用取引や先物などの特別な口座が必要で、損失が元手を超える場合もあります。仕組みを十分に理解してから扱ってください。

第5章資金管理 — いちばん大事な章

考え方 どの手法を選ぶかより、1回の取引でいくらまで失ってよいかを先に決めることのほうが、結果に大きく影響します。どんな手法でも連敗は必ず起きるためです。

損失は、取り戻すのがどんどん難しくなる

事実これは計算で確かめられます。資金が減ると、元に戻すために必要な利益率は、失った率より大きくなります。

失った割合残った資金(100万円の場合)元に戻すのに必要な利益率
10%90万円約 11%
20%80万円25%
30%70万円約 43%
50%50万円100%
80%20万円400%

計算式:必要な利益率 = 失った割合 ÷ (1 − 失った割合)。たとえば 50% 失うと、0.5 ÷ 0.5 = 1、つまり 100% 必要です。

1回の損失は、資金の1〜2%まで

常識 多くの入門書で、1回の取引で失う金額を資金の1〜2%以内にする、という目安が紹介されています。

事実1回の損失を資金の一定割合に固定したとき、連敗でどれだけ減るかは計算できます。

1回の損失5連敗後に残る資金10連敗後に残る資金
1%約 95.1%約 90.4%
2%約 90.4%約 81.7%
5%約 77.4%約 59.9%
10%約 59.0%約 34.9%

計算式:残る資金 = (1 − 1回の損失)を連敗の回数だけ掛け合わせたもの。

買う金額の決め方 — 損切りの位置から逆算する

常識「いくら買うか」は気分で決めず、損切りの位置から逆算します。

  1. 1回で失ってよい金額を決める。
    例:資金 10,000 USDT の 1% = 100 USDT。
  2. 買う価格と損切りの価格を決め、その差が何%かを出す。
    例:100 で買い、98 で損切り → 2%。
  3. 失ってよい金額を、その%で割る。
    例:100 ÷ 0.02 = 5,000 USDT 分を買う。

こうすると、損切りにかかったときの損失は 5,000 × 2% = 100 USDT となり、最初に決めた金額に収まります。 (実際には手数料が加わります。)

リスクリワード — 勝率だけでは決まらない

常識 「負けたときの損失」に対して「勝ったときの利益」が何倍かを、リスクリワード(損益比)と呼びます。損切りが 100、利確が 200 なら「1 対 2」です。

事実手数料を無視すると、損益がちょうどゼロになる勝率は、次の式で計算できます。

損失 対 利益トントンになる勝率意味
1 対 0.5約 67%3回に2回勝っても、やっとゼロ
1 対 150%半分勝てばゼロ
1 対 2約 33%3回に1回勝てばゼロ
1 対 325%4回に1回勝てばゼロ

計算式:トントンの勝率 = 1 ÷ (1 + 利益の倍率)。1 対 2 なら 1 ÷ 3 = 約 33% です。

考え方 「勝率が高い手法が良い手法」とは限りません。勝率 70% でも、勝ちが小さく負けが大きければ資金は減ります。勝率と損益比は、必ずセットで見てください。

第6章デモトレードでの練習のしかた

このサイトのデモトレードは、仮想の資金で売買の練習ができる機能です。実際のお金は動きません。

練習の進め方

  1. 手法を1つだけ決める。第4章から1つ選び、買う条件・損切り・利確を文章で書き出します。
  2. 条件がそろったときだけ売買する。「なんとなく上がりそう」では入りません。
  3. 注文と同時に、損切りと利確の価格を入れる。あとで決めようとすると、決められなくなります。
  4. 30回くらい続ける。途中で手法を変えると、何が良くて何が悪かったのか分からなくなります。
  5. 「成績を分析」で振り返る。数字を見て、直す点を1つだけ決めます。

成績の数字の読み方

勝率
常識決済した回数のうち、利益で終わった割合です。単独では良し悪しを判断できません(第5章を参照)。
プロフィットファクター
常識利益の合計 ÷ 損失の合計。1 より大きければ全体でプラス、1 より小さければマイナスです。
最大ドローダウン
常識資金がいちばん多かった時点から、最大でどれだけ減ったか。これが大きい手法は、実際のお金では続けるのが苦しくなります。
平均利益 / 平均損失
常識勝ったとき・負けたときの1回あたりの平均です。平均損失が平均利益よりずっと大きいなら、損切りが遅れているサインです。

デモと実際の取引の違い 考え方

  • 約定のしかたが違います。デモは表示中の価格でそのまま約定しますが、実際は注文の量や混み具合によって、不利な価格で約定することがあります(スリッページ)。
  • 気持ちが違います。自分のお金が減っていくと、決めたルールを守るのが急に難しくなります。デモで勝てても、実際に勝てるとは限りません。
  • 回数が少ないうちは、偶然の影響が大きいです。10回勝っただけでは、手法が良いのか運が良かったのか区別できません。
  • 利確・損切りの判定は、このページを開いている間だけです。閉じている間に価格が届いても、決済されません。

第7章よくある失敗

考え方初心者がつまずきやすい点を、なぜ起きるのかとあわせてまとめます。

損切りを動かしてしまう
「もう少し待てば戻るかも」と考えて損切りを遠ざけると、小さな負けが大きな負けに変わります。損を確定させる痛みを避けたい気持ちが原因です。損切りは、注文の前に決めて、あとから不利な方向へ動かさないと決めておきます。
負けを取り返そうとして金額を増やす
負けた直後に大きく張ると、次の負けで資金が一気に減ります。第5章の表のとおり、大きく減った資金は戻すのが難しくなります。
急に上がった銘柄に飛びつく
大きく上がったあとに買うと、いちばん高いところで買うことになりがちです。「乗り遅れたくない」という気持ちが原因です。条件がそろうまで待つ、と決めておきます。
インジケーターを増やしすぎる
指標が多いほど安心に感じますが、判断はかえって遅く、あいまいになります。
記録を付けない
記録がないと、同じ失敗を繰り返していても気づけません。このサイトでは、取引の履歴を CSV で保存できます。「なぜ入ったか」を1行ずつ書き添えると、あとで役に立ちます。
大きな流れに逆らう
日足が下向きのときに短い足で買うと、小さな上げのあとに来る大きな下げに巻き込まれやすくなります。長い足の向きを先に確かめます。

第8章用語集

ロング / ショート
買いから入るのがロング、売りから入るのがショートです。
ポジション(建玉)
買ったまま、または売ったままで、まだ決済していない持ち高のことです。
決済
ポジションを反対の売買で閉じて、損益を確定させることです。
利確(利益確定) / 損切り
利益が出ている状態で決済するのが利確、損失が出ている状態で決済するのが損切りです。
含み益 / 含み損(評価損益)
まだ決済していないポジションの、いまの時点での損益です。決済するまで確定しません。
成行(なりゆき)注文
価格を指定せず、いまの価格ですぐに売買する注文です。このサイトのデモトレードは成行のみです。
トレンド / レンジ
一方向に進んでいる状態がトレンド、一定の幅を行き来している状態がレンジです。
押し目 / 戻り
上昇の途中の一時的な下げが押し目、下落の途中の一時的な上げが戻りです。
サポート / レジスタンス
下げが止まりやすい価格帯がサポート、上げが止まりやすい価格帯がレジスタンスです。
ボラティリティ
値動きの大きさのことです。
レバレッジ
元手の何倍もの金額を取引するしくみです。利益も損失も倍率の分だけ大きくなります。このサイトのデモトレードにはありません。
スリッページ
注文した価格と、実際に約定した価格のずれです。
ステーブルコイン
価格が米ドルなどとほぼ同じになるよう設計された暗号資産です。USDT、USDC など。
ミームコイン
ネット上のジョークや流行をもとに作られた暗号資産です。DOGE、PEPE など。
